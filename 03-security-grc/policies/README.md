# Security and Privacy Policies (VitaClin, fictitious)

Write each policy short (2 to 4 pages), in a standard structure:

1. Purpose
2. Scope
3. Roles and responsibilities
4. Policy statements (the rules, in "must" form)
5. Exceptions and how to request them
6. Non-compliance
7. Related documents and ISO/IEC 27002 controls
8. Version, owner, approval and review date

| File | Policy | Main ISO/IEC 27002:2022 controls |
|---|---|---|
| `information-security-policy.md` | Information Security Policy (top-level) | 5.1 |
| `access-control-policy.md` | Access control, authentication and access reviews | 5.15, 5.16, 5.17, 5.18, 8.5 |
| `backup-policy.md` | Backup and restore testing | 8.13 |
| `retention-disposal-policy.md` | Data retention and secure disposal | 5.33, 8.10 |
| `acceptable-use-policy.md` | Acceptable use of assets | 5.10 |
| `privacy-policy-internal.md` | Internal privacy and personal data protection policy | 5.34 |

> Check each control number against the standard or the framework loaded in CISO Assistant before publishing.
